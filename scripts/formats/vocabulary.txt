# mtest's report vocabulary, one fact per line.
#
# The product and the harness each check themselves against this file:
# tests/unit/test_vocabulary_snapshot.mojo rebuilds every section from the
# runner's own tables, and scripts/tests/test_vocabulary.py reconciles the
# harness copies. Neither side owns the file; both compare against it.
#
# The three surfaces spell one outcome three ways on purpose. The console
# token is glyph-free ASCII with hyphens, the report label is the report
# layer's own underscore spelling, and the JSON token is frozen lowercase on
# the wire. Nothing may collapse them into one set.
#
# Grammar: blank lines and lines starting with '#' are ignored. Every other
# line is space-separated fields, and the first field names the section.
#
#   outcome <code> <console-token> <report-label> <json-token>
#   exit <name> <code>
#   event model <NAME>
#   event wire <token>
#   stream_version <n>
